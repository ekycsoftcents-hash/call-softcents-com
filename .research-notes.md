# External research notes

1. FreeSWITCH Event Socket is a TCP-based interface for external call control and event handling: https://developer.signalwire.com/freeswitch/integration/event-socket/
2. FreeSWITCH inbound Event Socket clients authenticate and issue commands such as originate: https://developer.signalwire.com/freeswitch/programming/esl-inbound
3. FusionPBX gateways define other VoIP servers/providers and outbound routes direct calls through them: https://docs.fusionpbx.com/en/latest/accounts/gateways.html
4. FusionPBX extensions define endpoint information for SIP devices: https://docs.fusionpbx.com/en/latest/accounts/extensions.html
5. `iamfarhad/laravel-rabbitmq` supports Laravel 12.x and 13.x, PHP 8.2+, RabbitMQ 3.13/4.x, and native `ext-amqp`; installation and worker usage are documented at https://packagist.org/packages/iamfarhad/laravel-rabbitmq

Implementation implication: Laravel dispatches queued jobs to RabbitMQ; a persistent worker loads the client-specific encrypted SIP profile and Caller ID, then authenticates to FreeSWITCH Event Socket on the FusionPBX server and issues the originate command. Asterisk ARI is not part of the intended final call path.

[02] WHY THIS SYSTEM
The calling problem is operational.
02
Synchronous calling makes the web request carry the telephony burden.
Campaigns need a reliable hand-off between the user interface, the call engine and the final call status — without exposing credentials or mixing tenants.
[01] BLOCKING REQUESTS
HTTP request waits while calls start, timeout or fail.
REQUIREMENT
Asynchronous queue with a persistent worker.
[02] DUPLICATE / LOST STATE
Retries can create duplicate calls or uncertain billing.
REQUIREMENT
Idempotency keys, bounded retry and event reconciliation.
[03] TENANT COLLISION
One client must never use another client’s identity.
REQUIREMENT
Per-client Caller ID, SIP profile and authorization boundary.
